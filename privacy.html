VIUK-Light / Privacy

プライバシーポリシー

VIUK-Light公式サイトにおける情報の取扱いを、現在の実装に基づいて説明します。

最終更新日：2026年8月29日

適用範囲

このポリシーは、VIUK-Lightが viuk-light.org で公開する公式サイトおよび、このリポジトリから配信する説明・ドキュメントページに適用されます。

GitHub、外部サイト、または個別にプライバシーポリシーを掲示するアプリ・サービスには、それぞれのポリシーが適用されます。

運営者

VIUK-Lightは、非営利・非法人のオープンソースプロジェクトです。

本サイトで取得しない情報

現時点の公式サイトには、利用者登録、問い合わせフォーム、メールマガジン、広告配信、VIUK-Light独自のアクセス解析、利用者行動を追跡するためのCookieや類似技術を設置していません。

また、Omoiの会話内容や回答を、本サイトを通じて入力・保存・収集する機能は設けていません。

GitHub Pagesによる配信

本サイトはGitHub Pagesを利用して配信しています。GitHubは、GitHub Pagesサイトへの訪問時に、セキュリティ目的で訪問者のIPアドレスを記録すると説明しています。GitHubが取り扱う情報、Cookie、保存期間、国外移転その他の事項は、GitHubのポリシーに従います。

VIUK-Lightは、本サイトに独自の解析タグを設置して訪問者のIPアドレスや閲覧履歴を取得し、利用者プロファイルを作成することはありません。

  • GitHub Pagesのデータ収集に関する説明を見る
  • GitHub Privacy Statementを見る

GitHub上の公開投稿

VIUK-LightのGitHubリポジトリでIssue、Pull Request、コメントその他の公開投稿を行う場合、GitHubアカウント名、投稿内容、添付ファイルその他の情報は、GitHub上で公開されることがあります。投稿する内容は、当該リポジトリの問題確認、保守、改善、議論のために利用します。

会話内容、氏名、住所、連絡先、健康情報、APIキー、アクセストークン、秘密のURLなどの個人情報・秘密情報を、公開IssueやPull Requestに投稿しないでください。公開投稿は、個人情報に関する非公開の問い合わせ窓口ではありません。

外部サービスと外部リンク

本サイトにはGitHubおよび各プロジェクトの外部ページへのリンクがあります。外部サイトへ移動した後の情報の取扱いは、各運営者のポリシーに従います。

ポリシーの変更

VIUK-Lightが、利用者登録、入力フォーム、メールによる個別問い合わせ受付、独自のアクセス解析、広告、バックエンドサービスその他の個人情報を直接取り扱う仕組みを追加する場合は、開始前にこのポリシーを更新し、取得する情報、利用目的、保存期間、第三者提供、問い合わせ手続を明示します。

本ポリシーを変更した場合は、このページの最終更新日を更新して公表します。
