概要

Omoi for Seriesは、恋人・家族・友だちとの会話や、ひとりでの振り返りを質問カードから始められるWebシリーズです。Couples、Family、Friends、Adults、Self-Careの5つを公開しています。

シリーズを選んだら、Lite / Deepで質問の踏み込み度を、通常 / 深掘りで追加の問いの表示方法を選びます。質問は一枚ずつランダムに表示され、「今日はここまで」でいつでも終了できます。

Omoi for Seriesについて目的・設計・Omoiとの違いはじめるURLから最初の質問まで5つのシリーズCouples / Family / Friends / Adults / Self-Care質問の深さと進め方Lite / Deepと通常 / 深掘り質問画面カードをめくる・進む・終了する安全な使い方相手のペースとデータの扱い技術仕様静的サイト・質問データ・公開状態ヘルプFAQと問題報告

公開データの概要

2026年10月17日に公開中の主質問は、5シリーズ合計706問です。追加の深掘りの問いは、この主質問数に含めていません。

Omoi for Couples232問
Omoi for Family166問
Omoi for Friends150問
Omoi for Adults94問
Omoi for Self-Care64問
質問の進め方枚数を事前に決めず、好きなだけ続けられます
回答と進行回答の入力・送信・保存機能はありません。設定と進行はページ内メモリだけで扱います

Adultsは18歳以上向けで、Deepの開始・再開前には内容の案内を表示します。Self-Careはひとりで使うシリーズで、医療的な診断・治療や心理状態の評価を行いません。
