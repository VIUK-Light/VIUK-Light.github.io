# SafeSearch 4 internal benchmark v1

`benchmark-v1.png`は、2026年10月17日に提供された内部独自ベンチマークv1の原表です。画像本体は変更していません。

`benchmark-v1.json`は原表の9カテゴリ・4世代の数値を転記したものです。`null`は原表の「未対応」を表し、0%とは区別しています。

SafeSearch 4列の測定対象は、ローカルカテゴリDB・URLルール・ローカルE5を使うmacOSネイティブ開発版です。公開中のX-filtering systemのEdge拡張機能を測った値ではありません。サイトでは、この測定対象に合わせて「SafeSearch 4 開発版」と表示しています。

指標は`category_attributed_block_recall`です。対応していて観測できた拒否期待ケースのうち、期待された理由カテゴリと一致してブロックした割合を示します。許可期待・未対応・未観測のケースは分母に含みません。一般的な精度や、許可期待ケースの誤拒否率とは異なります。

SafeSearch 4列の分子・分母は保存済みの集計結果と照合しています。測定は再実行していません。非公開コーパス、個別ケースのURL、レポート本体はこのアセットに含みません。
