データ構造

643件の質問を、Levelだけでなく論点・視点・配慮度まで検査できるJSONとして管理します。

現在のデータセット

Level 1163件 — 身近な経験から始める短い入口
Level 280件 — 日常・集団・境界線から意見の違いへ進む橋渡し
Level 3168件 — 制度・社会・役割の判断。全件にdetail.text
Level 4232件 — 個人的利害・倫理的トレードオフ。全件にdetail.text
合計643件

共通フィールド

id全Levelで重複しない固定ID
level配置ファイルと一致する1〜4の整数
sensitivity難しさではなく、話す前に配慮が必要な度合い
category12の上位分類
topic具体的な論点。検索・編集・近重複確認の軸
question画面に表示する問題文

Level 3・4の追加フィールド

perspectiveaffected / actor / decision_maker / observer
role任意。parent、teacher、friendなど具体的な立場
detail.text結論を決めず、対立・背景・条件を説明する文章
detail.sources任意。出典タイトルとHTTP(S) URL
content_warning任意。高リスク内容の管理値配列
{
  "id": "example-001",
  "level": 4,
  "sensitivity": 4,
  "category": "ethics_and_decision_making",
  "topic": "example_tradeoff",
  "perspective": "decision_maker",
  "question": "...",
  "content_warning": ["crime_and_punishment"],
  "detail": { "text": "...", "sources": [] }
}
