技術仕様

静的ファイルを配信する5シリーズ共通の構成と、公開中の質問・深掘りを読み込む条件を説明します。

このページ
構成ファイルとURL質問の選択ロジック質問データと深掘りの公開条件正本と公開状態

構成

フロントエンドHTML / CSS / JavaScript。5シリーズが共通UIを使います
配信GitHub Pages。公開元はOmoi-for-Seriesのmainブランチのルートです
ビルド工程公開時のビルド工程はありません
質問データシリーズごとのJSONと、公開状態を管理するマニフェスト
回答用バックエンドありません。回答の入力・送信・保存機能はありません
セッション状態設定、質問数、使用済みIDはJavaScriptのメモリ上だけで保持します
表示言語と書体日本語。BIZ UDPゴシックをGoogle Fontsから取得し、取得できない場合はOSの書体を使用します

ファイルとURL

index.html5シリーズへのリンクと、全体の使い方への入口
couples/ / family/ / friends/恋人・家族・友人向けの入口
adults/ / self-care/18歳以上向け・ひとり向けの入口
shared/app.jsLite / Deep、通常 / 深掘りの設定、AdultsのDeep開始前の案内、カード表示、終了操作を管理
shared/question-engine.mjs踏み込み度の判定、ランダム選択、裏面の補助問い
shared/content-policy.mjsデータ形式、生成元、レビュー状態、深掘りの採用条件を検査
shared/series-manifest.json各シリーズの公開状態、質問ファイル、プレビュー設定
shared/questions/*.json5シリーズの主質問。Adults / Self-Careは各質問にfollowUpも保持
shared/followups/*.jsonCouples / Family / Friendsの個別の深掘り。レビュー状態により採用を制御

質問の選択ロジック

01

公開設定とデータを読み込む

ページのdata-audienceと公開マニフェストから対象のJSONを決めます。新形式のデータでは公開状態、質問形式、作成元、レビュー状態を検査します。

02

Lite / Deepで絞る

質問のintensityを使います。既存3シリーズでは、Level 1〜2をLite、3〜4をDeepへ対応させます。画面にはLevelを表示しません。

03

一枚ずつランダムに選ぶ

選択した踏み込み度のプールから一枚ずつ引きます。未使用IDを優先し、周回時は可能なら直前の質問を避けます。セッションの固定枚数や上限はありません。

04

会話スタイルで裏面を切り替える

通常は主質問だけ、深掘りは「次へ」で裏面の問いも表示します。スタイルはLite / Deepとは独立しています。AdultsのDeepでは、開始と「もう一度」の両方でrenderDeepWarningを経由します。「続ける」で開始し、「戻る」またはEscapeキーで選択画面へ戻ります。

05

進行をメモリで保持する

使用履歴は同じページ内で保持します。再読み込みやLite / Deepの変更で履歴をリセットします。回答を保存する処理や進行の永続化はありません。

質問データと深掘りの公開条件

2026年10月17日時点の公開主質問数と、実際に採用する裏面の問いです。

シリーズ主質問裏面の問い
Couples232問。Loves由来95問・編集137問個別232文はpendingのため本番未採用。シリーズ共通の補助問いを表示
Family166問。編集質問個別166文はpendingのため本番未採用。シリーズ共通の補助問いを表示
Friends150問。編集質問個別150文はpendingのため本番未採用。シリーズ共通の補助問いを表示
Adults94問。全質問approved各質問のfollowUpを表示
Self-Care64問。全質問approved各質問のfollowUpを表示

Couples / Family / Friendsの個別深掘りは、データを読み込んでも、レビュー状態がapprovedになるまで本番では合成しません。現在の裏面にはquestion-engine.mjsのシリーズ共通の問いを使います。開発用プレビューは本番と区別して制御します。

Adults / Self-Careは、マニフェストと質問データの両方がpublishedで、各質問がapprovedの状態です。releaseApprovalには2026年10月16日の公開指示を記録しています。外部の専門審査を受けたという記録ではありません。

正本と公開状態

実装と質問データの正本は、Omoi-for-Seriesリポジトリです。公開中の内容はmainブランチで確認できます。この資料は、2026年10月17日の公開コミットc2fb80bに合わせています。同時点のBetaブランチとmainブランチは、ファイル内容が同じです。

Couplesの元データと公開デッキは件数が異なります。Loves由来の正本701問をもとに公開用に整理した222問に、新しいDeep10問を追加した232問を使っています。出典と再生成の情報はtools/PROVENANCE.mdとREADMEで確認できます。
