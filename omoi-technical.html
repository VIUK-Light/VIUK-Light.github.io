技術仕様

4カテゴリから始める画面構成、質問JSONの読み込み、ヒント・背景・戻る・終了の実装を説明します。

フロントエンドHTML / CSS / JavaScript

画面とファイル

開始index.htmlの「はじめる」からselect.htmlへ進みます
選択select.jsが4カテゴリの選択を内部のLevelへ対応させます。問題数は指定しません
開始前の案内カテゴリ3はwarning3.html、カテゴリ4はwarning.htmlを経由します
質問question.html?level=1〜4で、question.jsが該当JSONを読み込みます
終了「ここで終える」の確認で「終了する」を選ぶとindex.htmlへ戻ります。選択カテゴリの問いを一巡した場合も同じです

質問一覧の並びと現在位置はページ内のメモリで扱います。再読み込みするとデータを読み直して並べ替えます。以前の問題数パラメータや専用の終了ページを前提とした案内は、現行画面には当てはまりません。

質問データ

2026年10月16日に、公開元の main / fe24acc と公開サイトを照合しました。以下の件数は、この版の質問JSONに基づきます。

Level 1163件 / sensitivity 1
Level 280件 / sensitivity 1〜2
Level 3301件 / 全件に背景文とヒント
Level 4362件 / 全件に背景文とヒント
合計906件

scenario、hints、termsは任意の補助情報です。Level 3・4ではperspectiveとdetail.textを持ちます。詳しい項目と集計はデータ構造を確認してください。

表示ロジック

読み込むLevelに対応したJSONを取得し、配列・Level・質問文・補助情報の型などを確認します。読み込みは15秒でタイムアウトし、失敗時は「再試行する」を表示します
並べる取得した質問をシャッフルし、そのカテゴリの一覧を順に表示します
場面と問いscenarioがある場合は問いの前に表示します。長文では場面文と問いを含めてレイアウトを調整します
補助情報ヒント配列がある場合に「会話のヒント」、背景文・出典・用語のいずれかがある場合に「問いの背景」を表示します
進む・戻る「次の問いを見る」で進み、「前の問い」で同じ並びの一つ前へ戻ります。次の問いへ進む際に回答は求めません
終える確認ダイアログで続行または終了を選びます。終了を確定するとホームへ戻ります

データとプライバシー

アカウント登録、回答入力、回答の保存・収集、広告、課金の機能はありません。質問JSONの取得などの配信通信は発生し、閲覧に伴うログがホスティング側に残る場合があります。回答を収集しないことは、閲覧時に一切の通信が起きないことを意味しません。
