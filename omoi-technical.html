技術仕様

Omoiを構成するHTML・CSS・JavaScript・JSONと、静的Webアプリとしての表示の流れを説明します。

このページ
構成画面とファイル質問データ表示ロジックプライバシー正本とライセンス

構成

フロントエンドHTML / CSS / JavaScript
質問データlevel1.json / level2.json / level3.json / level4.json
バックエンドなし。静的サイトとして動作
ビルドツール不要
アカウント不要

画面とファイル

開始

index.htmlからselect.htmlへ進みます。

選択

select.jsがLevelと問題数を受け取り、次のURLを組み立てます。

質問

question.jsがJSONを読み込み、シャッフルして質問を表示します。

終了

選択した問題数を終えるとfinish.htmlへ進みます。

質問データ

Level 1163件 / sensitivity 1
Level 280件 / sensitivity 1〜2
Level 3168件 / すべてに解説
Level 4232件 / すべてに解説
合計643件

質問オブジェクトには、質問文、Level、上位カテゴリ、topic、sensitivityが含まれます。Level 3・4ではperspectiveとdetail.textを必須とし、高リスクの内容には必要に応じてcontent_warningを記録します。

表示ロジック

01

読み込む

選択したLevelのJSONを読み込みます。

02

選ぶ

質問をシャッフルし、選択した問題数だけ表示します。

03

進む

「次の質問」と「今回は話さない」は、どちらも次の質問へ進みます。

04

解説する

detail.textがある質問だけ「この問いを知る」を表示します。

プライバシー

公式READMEでは、アカウント不要、回答の保存なし、回答の収集なし、広告なし、課金なしと説明されています。会話は目の前の相手と行うことを中心に設計されています。
